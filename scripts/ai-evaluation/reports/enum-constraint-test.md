## 结论

1. **越界:** 枚举 Prompt 在解析成功的样本上，category/color 越界显著减少（目标方向有效）。
2. **稳定性:** 部分图片（如 shoes）生产臂已很稳；bra 在枚举臂成功时 category 收敛到「内衣」、color 到「肤色」，但成功次数少。
3. **副作用:** 枚举臂 JSON 解析失败率明显上升（结构完整性变差），拉低可用样本，整体「稳定率」不可单独解读为全面胜利。
4. **建议:** 枚举约束有助于取值空间收敛，但需与 JSON 完整性约束一并实验后再考虑合入生产；本轮**不替换**生产 Prompt。
