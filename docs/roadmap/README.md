# 路线图（Roadmap）

本目录存放未来功能规划，不替代具体版本记录（`docs/versions/`）。

## 版本原则

开发顺序必须遵守：

```text
数据准确性
  → 分类基础
    → AI 识别
      → AI 推荐
```

**不要提前开发推荐功能。** 数据口径与季节等分类基础未完成前，不得开工 AI 今日穿搭推荐 / 打卡真实识衣匹配等能力。

|------|------|

## 阶段对照

| 阶段 | 主题 | 对应原则 |
|------|------|----------|
| v1.1.0-alpha3 | 数据可信度优化 | 数据准确性 |
| v1.1.0-beta | 衣橱体验完善（季节、灵感） | 分类基础 |
| v1.2.0 | AI 衣橱助手 | AI 识别 → AI 推荐 |
