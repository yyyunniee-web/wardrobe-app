# 路线图（Roadmap）

本目录存放未来功能规划，不替代具体版本记录（`docs/versions/`）。

## 版本原则

开发顺序必须遵守：

```text
数据准确性
  → 分类基础
    → AI 识别
      → AI 推荐
```

**先保证数据准确，再做 AI 推荐。**  
数据口径未修正前，不得开工 AI 今日穿搭推荐 / 打卡真实识衣匹配 / 自动搭配等能力。
