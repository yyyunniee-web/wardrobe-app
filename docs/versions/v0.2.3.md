## 架构调整（本仓可落地）

浏览器只依赖**前端同源**（部署域），API 与图片经反代：

```
用户（大陆）
  └─ 前端域（Vercel 或前面再挂国内 CDN）
        ├─ /          静态壳（已去除 Google Fonts / Tailwind CDN / jsDelivr）
        ├─ /api/*  →  Cloudflare Worker
        └─ /media/* →  R2 公网桶
```

- `photo_url` 仍存 R2 绝对地址（DB 不变）
- 展示时改写为 `/media/...`
- Vision 仍向 Worker 传 R2 绝对地址（Worker 侧拉图）

## 本版改动

### 前端入口

- 去掉 `cdn.tailwindcss.com`、Google Fonts、`jsdelivr` 黄历 CDN
- Tailwind 由 Vite 打包（`src/index.css`）
- `lunar-javascript` 改为 npm 依赖

### API 入口

- `API_BASE` 默认 `/api`
- `vercel.json` + Vite `server.proxy` 反代到 Worker

### 图片入口

- 展示 URL：`r2.dev` → `/media/...`
- `vercel.json` 反代到 R2
- SW 不拦截 `/api`、`/media`（避免失败回落到 HTML）

## 自定义域名接入（本轮：先不接国内 CDN）

仅靠 `*.vercel.app` 大陆仍可能不通。v0.2.3 已把 `/api`、`/media` 收敛到前端同源；**绑自定义域后 rewrite 自动跟域名生效，无需改 env。**

### 前置

1. 先将本仓 v0.2.3 变更合并并部署到 Vercel **Production**（当前未推送前线上仍是 v0.2.2）
2. 准备一个你已持有的域名（apex 或子域均可，例如 `wardrobe.example.com`）

### 环境变量

| 变量 | 绑自定义域时 |
|------|----------------|
| `VITE_API_BASE` | **不要设**（默认 `/api`） |
| `VITE_IMG_PUBLIC_BASE` | **不要设**（默认 `/media`） |
| `VITE_WORKER_ORIGIN` / `VITE_R2_PUBLIC_HOST` | 无需改（仅文档/回退用） |

### Rewrite 与域名

`vercel.json` 的 `/api/:path*`、`/media/:path*` 按**路径**匹配，对 `*.vercel.app` 与自定义域同等生效。浏览器只打同源相对路径，不依赖硬编码生产域名。

### DNS（在域名注册商）

1. Vercel → 项目 → **Settings → Domains → Add**
2. 按控制台提示配置（以控制台显示值为准）：
   - **子域**（推荐先用）：`CNAME` → Vercel 给出的 `*.vercel-dns-*.com`
   - **apex**（`example.com`）：`A` → `76.76.21.21`（或以卡片为准）
3. 等到 Domains 状态为 **Valid**，HTTPS 证书签发完成
4. （可选）同时加 `www` 并设跳转到主域

### 上线验收 checklist（关 VPN · 大陆网络）

- [ ] 自定义域可打开，设置页版本为 **v0.2.3**
- [ ] Network：列表请求为 `https://你的域/api/...`，状态 200
- [ ] Network：图片为 `https://你的域/media/...`，状态 200，缩略图可见
- [ ] 上传一张新图后预览/列表正常（仍经 `/api/upload-image`）
- [ ] AI 识别仍可用（Beta2.2，不回归）
- [ ] `*.vercel.app` 旧地址仍可作回滚备用（不解绑亦可）

若自定义域仍大面积失败 → 再评估国内 CDN（本轮不做）。
