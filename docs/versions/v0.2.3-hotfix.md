# v0.2.3-hotfix — 回退 Vercel 同源反代

## 背景

国内无 VPN 实测：首屏 2–4 分钟、上传常失败、`/media` 预览失败，体验差于 v0.2.2。  
根因：`浏览器 → Vercel → Worker/R2` 多一跳，大陆环境下 Vercel 成为瓶颈。

## 本 hotfix 变更

| 项 | 处理 |
|----|------|
| `API_BASE` | 默认恢复直连 `https://wardrobe-api.yyyunniee.workers.dev` |
| 图片展示 | 默认不再改写为 `/media`，直接使用 R2 `photo_url` |
| `vercel.json` | 移除 `/api`、`/media` rewrite |
| Vite proxy | 移除本地 `/api`、`/media` 代理 |

## 保留（不变）

- 应用版本展示仍为 **v0.2.3**
- Beta2.2 AI / OCR 后台日期 / Vision 20s timeout
- 自托管静态资源（无 Tailwind CDN / Google Fonts / jsDelivr）
- 上传逻辑、AI prompt、evaluation、D1、R2 对象与 `photo_url` 存库

## 恢复后的数据面链路（对齐 v0.2.2）

```
浏览器 → Vercel（仅 HTML/JS/CSS）
浏览器 → workers.dev（API / upload-image / ai/vision）
浏览器 → r2.dev（img 直连）
```

## 本地确认要点

- 构建产物中 `API_BASE` 为 Worker 绝对地址，而非 `"/api"`
- `toDisplayPhotoUrl(r2Url)` 返回原 R2 URL（不带 `/media`）
- 设置页仍显示 `v0.2.3` / `Beta2.2`

## 部署

- Production：https://wardrobe-app-lilac.vercel.app
- 本 hotfix 随发布推送 Production（见 git commit）
